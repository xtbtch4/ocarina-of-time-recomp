# Local NUP build kit (Windows)\n\nThis kit builds `oot.exe` from a NUP file that remains on your own PC.\n\n## Requirements\n- Windows 10/11 x64\n- Python 3.14 x64 (the NUP reader uses Python's built-in `compression.zstd`)\n- MSYS2 installed at `C:\\msys64`, with the UCRT64 compiler and libraries listed by `BUILD-NUP.bat`\n\nOpen the **MSYS2 UCRT64** terminal and install/update packages using the commands printed by the launcher if needed. Then double-click `BUILD-NUP.bat`.\n\nThe launcher displays the NUP package table and asks which package index to extract.\n\n## Local-only data\nThe `.nup`, extracted ExeFS/RomFS, generated C, object files, and `oot.exe` are created locally. The launcher does not upload them. Do not commit `build/` or `generated/` contents.\n\n## Output\n`build/v<version>/oot.exe`\n\nIf the build fails, keep the console output; it identifies the missing dependency or failing step.\n
